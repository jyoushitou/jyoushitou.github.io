# RUST

## 复合类型

- 将多个值放到一个类型里

### 元组

- 创建了一个元组

```rust
let tup:(i32,f64,u8)=(500,6.4,1);
```

#### 获取数组元素

##### 使用模式匹配法

```rust
fn main() {
   let tup:(i32,f64,u8)=(500,6.4,1);
   let (x,y,z)=tup;
   println!("{}，{}，{}",x,y,z);
}
```

###### 使用点标记法

```rust
fn main() {
   let tup:(i32,f64,u8)=(500,6.4,1);
   println!("{}，{}，{}",tup.0,tup.1,tup.2);
}
```

### 数组

- 每个元素类型一致
- 长度固定

```rust
let a = [1,2,3,4,5];
```

- 存放数组的数据在栈上
- 数组没有vector灵活，和c++一样

#### 类型

- [类型;长度]

```rust
let a:[i32;5]=[1,2,4,5];
```

- [值;长度]

```rust
let a=[3;5];
```

- 超过范围的使用会报错
- 和其他语言一样

# MySQL

## SQL优化3

### count

- MyISAM会把一个表的总行数存在磁盘上
- InnoDB会在之心count(\*)中读出计数
- 自己计数
- count()聚合函数
- count()≠NULL,则+1

#### count(字段)

- 没有not null有约束，则把整个表的每行字段读出，返回给服务层，判断是否为NULL，不为NULL则计数累加
- 有not null约束，每行读出，返回给服务层，直接按行累加

#### count(1)

- 遍历整张表，不取值，放一个数字'1'进去，直接按行累加

#### count(\*)

- 不会全部字段取出，专门做优化，不取值，服务层按行累加

### update

- 无索引的情况下使用表锁

## 视图

- 一种虚拟存在的表，视图的数据并不在数据库中实际存在
- 只是一条预编译的 SQL 语句，每次查询视图时，数据库会动态执行对应的 SELECT 语句，从底层表实时取数。

### 创建

```sql
create [or replace] view view_name[(list_name)] as select语句 [with [cascaded | local] check option]
```

### 查询

#### 创建语句查询

```sql
show create view view_name;
```

#### 查询数据

```sql
select * from view_name
```

#### 修改

```sql
create [or replace] view view_name [(list_name)] as select语句 [with[cascaded|local] check option]
```

```sql
alter view view_name[(list_name)] as select语句 [with[cascaded|local] check option]
```

#### 删除

```sql
drop view [if exists] view_name [,view_name,……];
```

# vue3

## class绑定

- 数据绑定的一个常见场景是操纵CSS class列表，因为处理比较复杂绑定时，通过拼接生成字符串时麻烦且易出错的，因此vue专门做了优化

```vue
<template>
  <p :class="{ active: isActive }">test bind class</p>
</template>

<script>
export default {
  data() {
    return {
      isActive: true,
    };
  },
};
</script>
```
- 实现了class的样式标签
```vue
<template>
  <p :class="{ active: isActive }">test bind class</p>
</template>

<script>
export default {
  data() {
    return {
      isActive: true,
    };
  },
};
</script>

<style>
.active{
  color:red;
  font-size:30px;
}
</style>
```
- 实现了放大和将字体替换成红色
### 多个元素的绑定
```vue
<template>
```
