# C++
## `dynamic_pointer_cast()`
- 标准库中用于 **`std::shared_ptr` 动态类型转换** 的函数模板。它和普通 `dynamic_cast` 作用类似，但操作对象是智能指针
## auto it_cl = req.find(boost::beast::http::field::content_length)
- 在 **Boost.Beast** 中从 HTTP 请求里查找名为 `Content-Length` 的头部字段，返回的是一个**字段迭代器**

# 网络
## keep_alive
### HTTP
- `Connection: keep-alive` 表示**这个 TCP 连接用完后不要立刻断开**，可以继续发下一个请求。
### TCP
- 这是 **TCP 协议层**的机制，用来检测对端是否还活着。当连接空闲一段时间后，系统自动发一个探测包，如果对端没回复就关闭连接。
