## 所有权

- rust的核心
- 运行程序时必须管理他们使用计算机内存的方式
- 有些语言使用gc自动回收
- 其他语言使用显式的分配和释放内存
- rust采用所有权管理内存
- 不会减缓运行开箱，因为他将所有内存管理提前到了编译前
- 跟踪代码哪些数据使用heap
- 最小化heap上的重复数据量
- 清理heap上未使用的数据以避免空间不足

### 栈内存（stack）和堆内存（heap）

- 在rust上是在stack上还是heap，对运行有很大的效率
- 其他同c/c++

### 所有权规则

- 每个值都有一个变量，这个变量是该值的所有者
- 每个值都只能有一个所有者
- 超出作用域会被删除

### 作用域

### 创建动态string

- 使用from函数从字符串字面值创建string类型

```rust
let s=String::from("hello");
```

- 这类字符串是可以被修改的
- 字符串字面值在编译时就知道他的内容
- string支持可变性
- 可以参考c++的智能指针
- drop函数，在走出作用域，rust会自动调用这个函数

### move

- 多个变量可以与同一个数据使用一种独特的方式来交互

```rust
let s1=String::from();
let s2=s1;
```

- 此时s2会得到s1的指针
- 都走完时，会导致二次释放
- rust会让s1失效，不能使用
- rust不会自动创建数据的深拷贝
- 可以使用深拷贝

### clone

- 深拷贝

```rust
let s1=String::from();
let s2=s1.clone();
```

- 此时s1和s2都可以使用
- 对于stack的数据使用复制（copy trait）
- 如果一个类型或者这个类型的一部分实现了drop trait，则rust不会让他copy trait

### copy trait的类型

- 任何简单标量
- 需要分配内存或者某种资源
- 整数，bool，char，所有的浮点，tuple

# HTML

## 表单元素与 label 的绑定

- 无障碍：屏幕阅读器能朗读出该控件对应的标签文字
- 可用性：点击 label 文本即可聚焦 / 激活对应控件（点击范围变大

### 隐式绑定（嵌套）

- 将控件直接嵌套在 <label> 内部：

```html
<label>
  用户名：
  <input type="text" name="username" />
</label>
```

- 将输入框与"用户名："绑定
- 这种写法对可点击控件（如 checkbox、radio）非常友好，对普通文本框也能正常工作
- 点击用户名就会进入输入

### 显式绑定（for + id）

- 兼容性最好，尤其适合 label 与控件不在同一容器/相隔较远

```html
<label for="username">用户名：</label>
<input type="text" id="username" name="username" />
```

- 同样是绑定用户名和输入框
- `id="username"`：给输入框起一个唯一的名字，页面里一般只能有一个同名的 `id`。
- `for="username"`：告诉浏览器“这个 label 对应哪个控件的 id”，值必须和控件的 `id` 完全一致。
- 确保了绑定的唯一性

### aria-labelledby（需要额外标签文本时）

- 当你想让一个控件绑定多个标签或跨区域的文本时：

```html
<h3 id="title">收货信息</h3>
<label id="nameLabel">收件人</label>
<input type="text" aria-labelledby="title nameLabel" />
```

- 屏幕阅读器朗读该输入框时，会读成类似：“收货信息 收件人，编辑文本”。
- 好处是：即使这个 `<label>` 没有用 `for` 绑定、也没有把 input 包进去，依然能提供可访问标签，而且还能额外组合标题文字。
- 但要注意：
- `aria-labelledby` 优先级高于 `<label for>`，如果同时存在会以它为准。
- 更好的写法通常是：用 `<label for>` 绑定 label，或只让 `aria-labelledby` 指向 `nameLabel`，标题留给页面结构。

### aria-label（无可视文本时）

- 控件没有可见文字标签，但需要无障碍名称：

```html
<input type="text" aria-label="搜索关键词" />
```

### 各表单元素的绑定细节

#### 1. input（文本框类）

- text / password / email / number / date / tel / url 等全部支持：

```html
<label for="email">邮箱</label> <input type="email" id="email" name="email" />
```

#### 2. checkbox / radio（特殊交互）

- 绑定后点击 label 会切换选中状态：

```html
<label for="agree">我已阅读并同意协议</label>
<input type="checkbox" id="agree" />
```

- 点击就勾选了

- 单选/复选组的标题用 fieldset + legend 绑定（比逐条 label 更语义化）：

```html
<fieldset>
  <legend>性别</legend>

  <label> <input type="radio" name="gender" value="male" /> 男 </label>

  <label> <input type="radio" name="gender" value="female" /> 女 </label>
</fieldset>
```

- `<fieldset>`去加框框

#### 3.select

- 选择

```html
<label for="city">所在城市</label>
<select id="city" name="city">
  <option value="bj">北京</option>
  <option value="sh">上海</option>
</select>
```

#### 4.textarea

```html
<label for="bio">个人简介</label>
<textarea id="bio" name="bio" rows="4"></textarea>
```

- 一个对话框

#### 5.button

- button 不能绑定 label，原因：

- `<label>` 内不可嵌套 `<button>`
- label[for="button-id"] 无效，点击 label 不会触发按钮
- 用按钮的自带文字

```html
<!-- ✅ 正确：按钮自带文本 -->
<button type="submit">提交订单</button>
```

- 来个巨型的按钮，去显示图标

```html
<!-- ✅ 只有图标时，用 aria-label 提供无障碍名称 -->
<button type="button" aria-label="关闭窗口">
  <svg>...</svg>
</button>
```

## input类型

- 决定浏览器渲染成什么控件、以及能输入什么内容

### text

- 文本框
- 默认值：输入单行文本框

```html
<input type="text" />
```

- value是为其添加默认值
- placeholder是为了添加提示词

### email

- 邮箱输入框
- 移动端会弹邮箱键盘，提交时会做格式校验（不过只是提示，不是严格拦截）

```html
<input type="email" placeholder="请输入内容" />
```

- value是为其添加默认值
- placeholder是为了添加提示词

### number

- 数字输入框
- 带上下步进按钮。只允许数字、小数点、`e` 等。可配合 `min`、`max`、`step`

```html
<input type="number" min="1" max="100" step="1" />
```

- min最小值
- max最大值
- step步长

### checkbox

- 复选框
- 可单独勾选或复选，提交时只有勾选的值才会发送

```html
<input type="checkbox" name="agree" value="yes" /> 同意
```

- value，勾选后的值

### radio

- 单选按钮
- 同 `name` 的一组里只能选一个

```html
<input type="radio" name="gender" value="male" /> 男
<input type="radio" name="gender" value="female" /> 女
```

### file

- 文件选择框
- 可以用来上传文件。

```html
<input type="file" accept="image/*" multiple />
```

- `multiple` 能选多个文件

### date

- 日期选择器
- 浏览器会弹日历面板。值格式是 `YYYY-MM-DD`

```html
<input type="date" />
```

## 表单验证属性

- 需要 JS 的场景：
- 1. 自定义校验规则（比如两个密码是否一致）
- 2. 动态校验（输入时实时检查，不只提交时）
- 3. 自定义错误提示样式/文案（默认气泡太丑）
- 4. 提交前异步校验（检查用户名是否已存在）
- 5. 通过 JS 读取/设置表单值：

```js
const form = document.querySelector("form");
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const data = new FormData(form);
  // 处理数据
});
```

### 1.必填校验

```html
<input type="text" required />
```

### 2.文本长度限制

```html
<input type="text" minlength="2" maxlength="10" />
```

- `minlength` 最少字符数
- `maxlength` 最多字符数

### 3.格式匹配

```html
<input type="text" pattern="[0-9]{11}" title="请输入11位数字" />
```

- 用正则表达式校验内容，配合 `title` 提供错误提示文字。

### 4.数值范围与步长

```html
<input type="number" min="1" max="100" step="1" />
```

- `min`、`max` 限制大小范围，`step` 控制合法步长，比如只能输入 1、2、3…不能输入 1.5。

### 5. 内置类型校验

```html
<input type="email" />
<input type="url" />
<input type="date" />
<input type="number" />
```

- 浏览器会根据 `type` 自动验证格式，比如 email 必须包含 `@`，url 必须合法链接，date 必须是日期格式。

### 补充几个要点：

- 没有 `name` 的 input 一般提交时不会把值带过去。`id` 主要给 JS / label 用，`name` 主要给表单提交用，两者不是一回事，但可以相同。
- `required`、`pattern` 等是浏览器原生验证，不满足时表单不会提交，并弹出气泡提示。
- 提交表单时可以用 `novalidate` 关闭原生验证：

```html
<form novalidate>...</form>
```

- 用 CSS 伪类可以视觉提示：

```css
input:valid {
  border-color: green;
}
input:invalid {
  border-color: red;
}
```
