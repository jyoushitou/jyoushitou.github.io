# RUST

## 所有权与函数

- 值传递给函数，要么移动要么复制
- 同时传参时将所有权传递给函数内部
- 返回值过程中也会发生所有权的转移
- 当一个值赋给其他变量是就会发生移动
- 当一个包含heap数据的变量离开作用域，他的值就会被drop清理
- 让函数使用值，但不获得所有权，可以使用引用

## 引用和借用

- 使用&去引用
- 引用允许你使用某些值而不使用所有权

```rust
fn fnc_name(s:&type_name)->utype_name
{

}
```

- 将引用作为函数参数的行为叫做借用
- 都需要声明类型为可变
- 只能有一个可变引用
- 不可以同时拥有一个可变引用和一个不变引用

### 悬空引用

- 和悬空指针类似
- RUST会保证引用在作用域内悬空

## 触发器

- 表进行操作时触发，自动执行触发器定义的语句集合
- MySQL只支持行级触发器
- 触发器有：
- insert型触发器
- update型触发器
- delete型触发器

### 创建

```sql
create trigger trigger_name
brfore/after insert/update/delete
on tb_name for each row
begin
    trigger_stmt;
end
```

### 查看

```sql
show triggers;
```

### 删除

```sql
drop trigger [schema_name.]trigger_name;
```

- 没有指定schema_name默认当前数据库

# MySQL连接池

- 通过连接池的tcp连接，server验证，4次挥手等时间节省
- 热点数据访问缓存

## 一般访问流程

- 1.tcp连接
- 2.server验证
- 3.发出sql请求
- 4.返回数据
- 5.关闭数据库
- 6.tcp4次挥手

## 使用连接池

- 看能否直接从缓存拿出数据，且连接不关闭

## 功能

### 初始连接量

- 服务器事先和MySQLServer创建initSize的connection连接（和线程池的事先创建线程类似）

### 最大连接量

- 当并发访问MySQL Server的连接量不够，将会创建新的连接，连接使用完后，再次归还到连接池中维护

### 最大空闲时间

- 当并发请求多了，之后再指定的最大空闲里面没有被使用，那么就会被回收，维持initSize的数量

### 连接超时

- 请求量过大，连接池内的连接数到达最大连接量，则通过阻塞的方式获取连接的时间如果超过connectionTimeout时间，返回获取连接失败，无法访问数据库

### 使用

### 属性选择器

```css
选择器 {
  属性: 值;
}
```

- `[attr]`只要含有该属性
- `[attr="val"]`属性值精确等于val
- `[attr~="val"]`属性值是以空格分隔的词列表，包含 val
- `[attr\="val"]`属性值以 val 开头，且紧跟 - 或正好等于 val
- `[attr^="val"]`属性值 以 val 开头（前缀匹配）
- `[attr$="val"]`属性值 以 val 结尾（后缀匹配）
- `[attr*="val"]`属性值 包含 子串 val（子串匹配）

### 伪类选择器

- 伪类用于选择 处于特定状态 的元素，使用单个冒号 :。它不改变 DOM，而是按状态匹配。

#### 动态伪类

- `:link`未访问过的链接
- `:visited`已访问过的链接
- `:hover`鼠标悬停时
- `:active`元素被激活（如按下鼠标）时
- `:focus`获得焦点时
- `:focus-within`自身或其子孙获得焦点时

#### 结构伪类

- `:first-child`父元素的第一个子元素
- `:last-child`父元素的最后一个子元素
- `:nth-child(n)`第 n 个子元素（odd/even/2n 等）
- `:nth-last-child(n)`从后往前数的第 n 个子元素
- `:first-of-type`同类型元素中的第一个
- `:last-of-type`同类型元素中的最后一个
- `:nth-of-type(n)`同类型元素中的第 n 个
- `:only-child`唯一的子元素
- `:not(selector)`排除匹配的元素
- `:empty`没有子元素（含文本节点）的元素

#### 表单状态伪类

- `:checked`勾选的 checkbox / radio / option
- `:disabled`禁用的表单控件
- `:enabled`可用的表单控件
- `:required`必填项
- `:optional`选填项
- `:valid`内容校验通过的输入框
- `:invalid`内容校验失败的输入框
- `:placeholder-shown`正在显示 placeholder 的输入框

#### 其他常用伪类

- `:root` — 文档根元素（相当于 html），常用于定义 CSS 变量
- `:target` — 当前被锚点（URL 的 #hash）指向的元素
- `:is() / :where()` — 选择器列表，:where() 优先级永远为 0
- `:has()` — 包含特定子孙元素的父元素（选择器条件）

### 伪元素选择器

- 伪元素用于选中元素中 并不真实存在的部分 或生成内容，使用双冒号
- `::before`在元素内容之前插入内容
- `::after`在元素内容之后插入内容
- `::first-letter`第一个字符（仅限块级元素）
- `::first-line`第一行文本
- ::selection`用户选中的文本
- `::placeholder`输入框的占位提示文字
- `::marker`列表项前面的标记符号
- `::backdrop`全屏元素（如 <dialog>、-video 全屏）背后的背景层

### CSS 优先级（特异性 / Specificity）

- 当多条规则同时选中同一个元素且属性冲突时，浏览器按 优先级 + 先后顺序 决定应用哪条。
- 1. 优先级计算规则
- 优先级 = 四个层级的计数 (a, b, c, d)，从高位到低位依次比较：
- `a` 内联样式 style="..."
- `b` ID 选择器 #id
- `c` 类、属性选择器、伪类 (.class、\[attr]、- :hover）
- `d` 元素、伪元素 (div、::before)
- `0` 通配符 \*、>、+、~、:where()
- 计数相同则按 源码中出现的先后顺序，后写的覆盖先写的；!important 权重最大，优先于所有普通声明。

#### 注意点

- 伪类是类级别：:hover 和 .class 同级，ul li:hover 与 ul li.active 优先级相同，后写的生效。
- 伪元素是元素级别：::before 与 li 同级。
- :is() 优先级取内部最高，而 :where() 永远是 0：

## 盒模型

- CSS 中每个元素都可以看作一个矩形盒子，由四个部分组成（从内到外）:

```结构
┌─────────────────────────────────────┐
│            margin（外边距）          │
│  ┌───────────────────────────────┐  │
│  │          border（边框）        │  │
│  │  ┌─────────────────────────┐  │  │
│  │  │        padding（内边距） │  │  │
│  │  │  ┌───────────────────┐  │  │  │
│  │  │  │    content（内容） │  │  │  │
│  │  │  └───────────────────┘  │  │  │
│  │  └─────────────────────────┘  │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

### 结构

- `content`实际内容（文字、图片等），受 width / height 控制
- `padding` 内容与边框之间的内边距，可设 4 个方向
- `border`边框，可设宽度、样式、颜色
- `margin` 盒子与其他元素之间的外边距（在元素外部，不参与元素实际占位计算，但影响布局间距）

### 计算总宽高的公式（默认 content-box）:

- 元素总宽度 = width + padding-left + padding-right + border-left + border-right
- 元素总高度 = height + padding-top + padding-bottom + border-top + border-bottom
- margin 不包含在元素自身尺寸内，但会影响它在布局中占用的空间：
  占用空间 = 元素总尺寸 + margin

### border-box（IE 怪异盒模型）

- width / height 包含 content + padding + border
- 即：width 就是元素最终渲染的宽度，padding 和 border 会从内部挤压内容区

```css
div {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid #000;
}
/* 实际总宽度 = 200px（就是声明的 width） */
/* 内容区宽度 = 200 - 20×2 - 5×2 = 150px */
```

### 对比图

```
content-box（width: 200px）        border-box（width: 200px）
┌─────────── 250px ───────────┐   ┌────────── 200px ──────────┐
│ margin                      │   │ margin                    │
│ ┌───────── 250px ─────────┐ │   │ ┌──────── 200px ────────┐ │
│ │   border 5px           │ │   │ │ border │ padding │     │ │
│ │ ┌────── 200px ──────┐  │ │   │ │  ┌──── 150px ────┐   │ │ │
│ │ │  padding 20px     │  │ │   │ │  │ content      │   │ │ │
│ │ │ ┌── 160px ──┐     │  │ │   │ │  └──────────────┘   │ │ │
│ │ │ │ content  │     │  │ │   │ └──────────────────────┘ │ │
│ │ │ └──────────┘     │  │ │   │ └────────────────────────┘ │
│ │ └──────────────────┘  │ │   └────────────────────────────┘
│ └───────────────────────┘ │
└───────────────────────────┘
```

- 使用border-box：
- 心智负担小：设置 width: 200px 就是最终宽度，不用反复加减 padding 和 border。
- 响应式布局更安全：配合百分比宽度时（如 width: 50%），不会因为 padding 导致溢出换行。
- 与框架一致：Bootstrap、Tailwind 等主流框架都默认使用 border-box。

### margin 的特殊性

- margin 不参与 box-sizing 计算，但它有两个常见坑：

#### 外边距合并（Margin Collapsing）

- 垂直相邻元素的 margin 会取较大值

#### 父子 margin 传递

- 父元素没有 padding / border / overflow 时，子元素的 margin-top 会"传"给父元素，用给父元素加 padding、border、overflow: hidden，或改用 padding

#### margin 正数 / 负数 / 百分比

```css
/* 正数：把元素推离正常位置或挤压其他元素 */
.element {
  margin-top: 20px; /* 向下移 */
  margin-left: -10px; /* 向左溢出，实现重叠效果 */
}

/* 百分比：相对于父元素的宽度（left/right）或高度（top/bottom）计算 */
.element {
  margin: 10%; /* 上下左右都是父宽度的 10% */
}
```

## CSS单位

### px——绝对单位

- 固定像素，不随父元素/根元素字号变化
- 适合边框、固定尺寸的 UI

### em——相对父元素字号

- `1em = 父元素 font-size`
- 嵌套会累乘，不直观：2em 的孙子可能是 8em 的效果

### rem——相对根元素 html 字号

- `1rem = html 的 font-size`（默认通常 16px）
- 不受嵌套层级影响，计算直观
- 修改 html 的 font-size 可全站等比缩放

```css
html {
  font-size: 16px;
}
.title {
  font-size: 2rem;
} /* = 32px */
.btn {
  padding: 1rem 2rem;
} /* = 16px 32px */
```

### vw / vh——视口单位

- `1vw = 视口宽度的 1%`，`1vh = 视口高度的 1%`
- `vmin` = 视口宽高中较小者，`vmax` = 较大者
- 适合全屏 banner、首屏大标题（字体大小随视口变化）

```css
.hero {
  width: 100vw;
  height: 100vh;
}
.big-title {
  font-size: 8vw;
}
```

### %——百分比

- width/height 相对父元素对应值
- padding/margin 都相对**父元素的宽度**（垂直方向上也是宽度！）
- font-size 相对父元素字号
- ⚠️ 父元素没设高度时，子元素 `height: 100%` 无效

### 单位速查表

| 单位  | 类型 | 相对谁     | 典型用途           |
| ----- | ---- | ---------- | ------------------ |
| px    | 绝对 | —          | 边框、固定尺寸     |
| em    | 相对 | 父元素字号 | 组件内部局部间距   |
| rem   | 相对 | 根元素字号 | 全局字号、间距系统 |
| vw/vh | 相对 | 视口       | 全屏、首屏、大标题 |
| %     | 相对 | 父元素尺寸 | 流式布局宽高       |

## BFC（块级格式化上下文）

### 什么是 BFC

- BFC 是一个独立布局区域，内部元素布局不影响外部，外部也不影响内部
- 常用于解决 margin 塌陷、浮动高度塌陷

### 触发方式

- `float: left/right`
- `position: absolute/fixed`
- `overflow: hidden/auto/scroll`（最常用）
- `display: flow-root`（推荐，无副作用）
- `display: flex/grid/inline-block`
- 根元素 html 自动

### 解决父子 margin 塌陷

- 父元素没有 padding / border / overflow 时，子元素 margin-top 会"传"给父元素
- 解法：
  1. 父元素加 `overflow: hidden` 或 `display: flow-root` 创建 BFC
  2. 父元素直接加 `padding-top`（推荐）
  3. 改用 flex/grid + gap 控制间距（终极方案）

```css
.parent {
  overflow: hidden; /* 创建 BFC，隔离子元素 margin */
}
/* 或 */
.parent {
  display: flex;
  flex-direction: column;
  gap: 20px; /* 告别 margin 合并 */
}
```

### 解决兄弟元素 margin 合并

- 相邻元素垂直 margin 取较大值（30px + 20px = 30px）
- 解法：将元素包在 BFC 容器内，或只用单方向 margin / gap

### 解决浮动高度塌陷

- 子元素 float 后父元素高度为 0
- 父元素创建 BFC 后，高度计算包含浮动元素

```css
.parent {
  overflow: hidden; /* BFC 高度包含浮动子元素 */
}
/* 或 */
.parent {
  display: flow-root;
}
/* 或 ::after 清除浮动 */
.parent::after {
  content: "";
  display: block;
  clear: both;
}
```

### 推荐全局写法

```css
/* 统一盒模型 */
*,
*::before,
*::after {
  box-sizing: border-box;
}

/* BFC 工具类 */
.bfc {
  display: flow-root;
}
```
