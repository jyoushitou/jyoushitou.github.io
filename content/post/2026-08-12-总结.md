# rust

## 常用集合

- 堆上的

### vector

#### 创建

```rust
let v:Vec<typ_name>=Vec::new();
```

```rust
let v=vec![1,2,3];
```

#### 放入元素

- 需要定义mut后才可以修改

```rust
v.push(value);
```

#### 删除

- 离开作用域后会被清理掉

#### 读数据

- 索引
- get()

#### 作用域

- 不可变的不能变可变的

#### 遍历

- for循环去遍历

```rust
for i in &t
```

- 修改也是，不过要加mut

### String

- 倾向暴露可能的错误
- utf-8编码
- 基于byte的集合
- 只提供字符串切片str/&str
- 来自标准库(还包含OsString/OsStr,CString/CStr)
- 是Vec<u8>的封装

#### 创建

- vec的操作适用于String
- to_String()也可以实现

```rust
let s=String::from("String_value");
```

#### 添加

```rust
s.push_str("String_value");
```

- 不会转移所有权

```rust
s.push('单个字符');
```

- -
- 其中一个变为引用就可以了
- 不用借用的话，所有权会把所有权到新变量

```rust
let s3=s2+&s1
```

- format

```rust
let s=format{"{}-{}-{}",s1,s2,s3};
```

#### 访问

- &String_type[String_key];会拒绝这样的访问

#### 函数

- bytes()字节数
- chars()unicode标量

#### 切割

```rust
let String_name1=&String_name2[key1,key2];
```

### HasMap<K,V>

- 键值对
- c++的unordered_map

#### 创建/添加

```rust
let mut Map_name=HashMap(<type_name>)::new();
Map_name.insert(String2_name,String_len);
```

- vec/tup

```rust
let Map_name:HasMap<_,_>=vec_name1.iter().zip(Vec_name2.iter()).collect()
```

#### 所有权

- copy trait,值会复制到HasMap
- 值移动，所有权也移动给HasMap
- 值插入Map，其所有权不变
- HasMap有效期间，引用值也得有效

#### 访问

- get方法

#### 更新/修改

- 一个K对应一个V

##### 用现有值V

```rust
map.insert(key,value);
```

##### 添加V

- entry判断是否存在

```rust
map_name.entry(Key).or_insert(value);
```

#### 切换函数

- 可以切换hasn的方法

## 对象的父子关系

- 类似windows的父子关系
- 父对象改变，则子对象也会改变
- 子对象的transform是 相对于父对象
- 父子对象一起移动则会计算其中心点的transform
