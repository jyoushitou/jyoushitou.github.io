# RUST

## 泛型

- c++的模版
- 编译器会使用占位符替换

```rust
fn 泛型名称<泛型类型>([参数]){}
```

- 也可用于结构体
- 枚举：

```rust
enum 结构体名称<T>{
    名称(类型)
}
```

- 方法可以

```rust
impl<T> 对象<T>{
    fn 方法名([参数])->&T
}
```

- 会执行单态化

## trait

- 描述某种类型具有哪些并且可以与其他类型共享的功能

### 定义

- 函数将方法签名放一起

```rust
trait trait名{
    函数签名;
}
```

- 根据功能能实现不同的方法

### trait约束

- 无法为外部类型实现外部trait
- 要在同意trait

### 默认实现

- 直接在trait的签名下使用

```rust
trait trait名称{
    fn 函数名称(){
        //实现
    }
}
```

- 他还可以调用其他方法

### 作为参数

- 用impl trait

```rust
fn 函数名(参数名:impl trait名){}
```

- 用trait bound

```rust
fn 函数名<T:trait名>(参数名:T){
}
```

#### where子句

- 绑定多个bound

```rust
fn 函数名<T,U>([参数]){
where
T:trait名+trait名
U:trait名
}
```

### 返回类型

- 必须指定类型
